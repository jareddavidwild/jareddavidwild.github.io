# Personal Portfolio Website

This repository contains the source code for my personal portfolio website.

The site showcases my professional experience, technical skills, projects, and career journey through an interactive and modern web experience. It combines responsive design, smooth animations, and real-time 3D graphics to create an engaging way for visitors to learn more about my work.

🌐 **Live Site:** https://jareddavidwild.github.io

## Features

* Interactive personal portfolio
* Professional experience and skills showcase
* Project highlights and accomplishments
* Responsive design for desktop and mobile devices
* Smooth scrolling and modern UI animations
* Real-time 3D graphics powered by Three.js

## 3D Experience

The website features a dynamic 3D ocean scene that is revealed as users scroll beyond the hero section. All 3D elements throughout the site are rendered using Three.js, creating an immersive visual experience while maintaining performance and responsiveness.

## Tech Stack

* **Vite** – Fast development environment and build tooling
* **Three.js** – Real-time 3D rendering and scene management
* **JavaScript (ES6+)**
* **HTML5**
* **CSS3**
* **Git & GitHub**
* **GitHub Pages** – Deployment and hosting

## Development

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## About

This portfolio serves as a living representation of my work and is continuously updated with new projects, skills, and professional experience. The goal is to combine strong software engineering principles with modern web technologies and interactive 3D experiences.
